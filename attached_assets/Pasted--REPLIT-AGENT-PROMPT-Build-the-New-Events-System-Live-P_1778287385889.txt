⭐ REPLIT AGENT PROMPT — Build the New Events System (Live + Pre‑Recorded)
I need you to build a new Events system for Studio Flow that supports live events and pre‑recorded events, fully integrated with Supabase and the existing app architecture.

The goals:

Replace the old static Events section

Use Supabase as the source of truth

Support both live and pre‑recorded events

Expose events via a clean Events page + Event Details page

Keep Custom Events and Contests logic intact

Follow these steps exactly.

1. Supabase: Create events table
Create a new table events with columns:

id — uuid, primary key, default uuid_generate_v4()

title — text, not null

description — text

event_type — text, not null ('live' or 'recorded')

start_time — timestamp with time zone, nullable (for scheduled/live)

duration_minutes — integer, nullable

price — numeric, default 0

is_paid — boolean, default false

location — text (e.g., “Virtual”, “Studio Flow Live Hall”)

thumbnail_url — text

video_url — text (for pre‑recorded / replay)

live_room_id — text (for live session / room reference)

created_by — uuid, references profiles.id or auth.users

created_at — timestamp with time zone, default now()

status — text, default 'upcoming' ('upcoming' | 'live' | 'ended' | 'cancelled')

Do not modify existing tables.

2. Backend: Events routes (ESM)
Create server/routes/events.js (or equivalent ESM route file) with:

GET /api/events
Returns all public events ordered by start_time ascending.

Optional query filters: status, event_type.

GET /api/events/:id
Returns a single event by id.

POST /api/events
Admin/creator only.

Creates a new event with payload:

title, description, event_type, start_time, duration_minutes, price, is_paid, location, thumbnail_url, video_url, live_room_id.

Auto‑set created_by from auth context if available.

PATCH /api/events/:id
Admin/creator only.

Update event fields (title, description, status, etc.).

DELETE /api/events/:id
Admin only.

Soft delete or hard delete (choose one and be consistent).

Mount in server/app.js:

js
import eventsRouter from "./routes/events.js";
app.use("/api/events", eventsRouter);
Use Supabase client consistent with existing backend.

3. Frontend: Events list page
Create src/pages/Events.jsx:

Fetch events from Supabase (or /api/events):

js
const { data: events, error } = await supabase

Group or visually distinguish:

Live events (event_type === 'live', status === 'live' or upcoming with start_time)

Render event cards with:

Title

Date/time (if applicable)

Price (Free / $X)

Thumbnail

Show video player using video_url.

Show ticket/paywall UI placeholder (do not implement Stripe here unless already wired; just keep the hook/button).
