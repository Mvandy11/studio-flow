2. FETCH ALL REQUIRED ANALYTICS DATA
────────────────────────────────────────
Implement Supabase queries for:

1) Total number of contests:
select count(*) from contests;

2) Total number of events:
select count(*) from events;

3) Total number of users:
select count(*) from profiles;

4) Total ticket purchases:
select count(*) from ticket_purchases;

5) Total revenue:
select sum(ticket_price * quantity) from ticket_purchases;

6) Total winners selected:
select count(*) from winner_history;

7) Unique winners:
select count(distinct user_id) from winner_history;

8) Recent activity (last 7 days):
- new users
- new contests
- new events
- new ticket purchases
- new winners
