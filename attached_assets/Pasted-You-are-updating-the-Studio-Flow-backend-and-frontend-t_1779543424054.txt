You are updating the Studio Flow backend and frontend to add full support for
recorded video uploads to event slots. Implement the following changes:

────────────────────────────────────────
1. BACKEND: Add upload endpoint
────────────────────────────────────────

Create a new route file:
server/routes/uploadRecordedVideo.js

Inside it, implement:

- POST /api/events/:eventId/upload-recorded
- Accept multipart/form-data with field: "video"
- Validate:
    - eventId exists
    - slot exists for that event
    - file is a video (mp4, mov, webm)
- Upload the file to Supabase Storage bucket "event-videos"
  using supabaseAdmin.storage.from("event-videos").upload(...)
- Generate a public URL using getPublicUrl()
- Update the event row:
      video_url = <public URL>
      status = 'recorded'
      start_time = now() (optional)
      end_time = now()
- Update the event_slot row:
      status = 'ended'
- Return JSON:
      { success: true, video_url }

Use supabaseAdmin, not the anon client.

────────────────────────────────────────
2. BACKEND: Register the route
────────────────────────────────────────

In server/index.js (or server.js):

import uploadRecordedVideo from "./routes/uploadRecordedVideo.js";

app.post(
  "/api/events/:eventId/upload-recorded",
  uploadRecordedVideo
);
