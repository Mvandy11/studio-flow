You are adding a unified LIVE VIDEO FEED system to both Studio Flow and DreamPort. 
This system must support YouTube Live, Twitch, Vimeo Live, and Cloudflare Stream.

GOAL:
Creators can paste a livestream URL and toggle “Go Live.”
Viewers can watch the live feed embedded inside both apps.
No backend streaming servers are required.

------------------------------------------------
STEP 1 — DATABASE UPDATES
------------------------------------------------

Add the following fields to the appropriate tables:

For creators/profiles:
- live_stream_url text
- live_stream_type text
- is_live boolean default false

For Studio Flow sessions/events:
- live_stream_url text
- is_live boolean default false

For DreamPort worlds/hubs:
- live_stream_url text
- is_live boolean default false

------------------------------------------------
STEP 2 — CREATE A SHARED LIVE PLAYER COMPONENT
------------------------------------------------

Create a new component:

src/components/LivePlayer.tsx

This component must:
- detect YouTube Live URLs and convert to embed format
- detect Twitch URLs and embed via Twitch player
- detect Vimeo Live URLs and embed via Vimeo player
- detect Cloudflare Stream URLs and embed via iframe
- return null if no URL is provided

Ensure the component is responsive and works in dark mode.

------------------------------------------------
STEP 3 — ADD “GO LIVE” UI FOR CREATORS
------------------------------------------------

Add a UI panel in both apps:

Studio Flow:
- Creator Profile Settings
- Session/Event creation/edit page

DreamPort:
- World/Hub edit page

UI fields:
- Input: livestream URL
- Dropdown: livestream type (youtube, twitch, vimeo, cloudflare)
- Toggle: “Go Live”

On save:
- update live_stream_url
- update live_stream_type
- update is_live = true

------------------------------------------------
STEP 4 — ADD LIVE FEED DISPLAY FOR VIEWERS
------------------------------------------------

Studio Flow:
- On session page, if is_live = true, show <LivePlayer url={live_stream_url} />
- On creator profile, show LIVE badge and player
- On feed, show LIVE NOW badge

DreamPort:
- On world/hub page, show <LivePlayer />
- Add LIVE badge to world cards
