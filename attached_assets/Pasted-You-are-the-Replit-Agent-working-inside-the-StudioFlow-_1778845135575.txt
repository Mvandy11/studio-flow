You are the Replit Agent working inside the StudioFlow codebase. Your task is to wire the contest winner-pull logic into the backend so that admins can:

- Pull one or more winners for an event/contest
- Ensure no repeat winners (using winner_history)
- Store winners with place_number and payout_amount
- Use Supabase with the service_role key on the server

Key tables:
- ticket_purchases (event_id, user_id, ticket_price, quantity, created_at)
- winner_history (id, user_id, event_id, contest_id, place_number, payout_amount, created_at)

────────────────────────────────────────
1. LOCATE BACKEND/API LAYER
────────────────────────────────────────
Find the serverless/API layer, likely:
- netlify/functions/api.js
- netlify/functions/*.js
- /api/contest-winner, /api/events, etc.

Identify the best place to add:
- POST /api/contests/:id/pull-winners

────────────────────────────────────────
2. CREATE ENDPOINT: PULL WINNERS
────────────────────────────────────────
Implement a handler:

POST /api/contests/:contestId/pull-winners

Request body:
- eventId (uuid)
- numberOfWinners (int)
- payouts: array of { placeNumber, payoutAmount }

Behavior:
1) For i from 1 to numberOfWinners:
   - Run a Supabase query to select a random eligible user:

     from ticket_purchases tp
     where tp.event_id = eventId
     and tp.user_id not in (select user_id from winner_history)
     order by random()
     limit 1

   - If no eligible user is found, stop and return what we have.

2) For each selected user:
   - Insert into winner_history:
     - user_id
     - event_id
     - contest_id (from route param)
     - place_number (from payouts[i].placeNumber)
     - payout_amount (from payouts[i].payoutAmount)

3) Return JSON:
   {
     winners: [
       { userId, placeNumber, payoutAmount }
     ]
   }

Use the Supabase service_role key on the server.

────────────────────────────────────────
3. ENSURE NO REPEAT WINNERS
────────────────────────────────────────
The Supabase query MUST exclude users already in winner_history:

supabase
  .from("ticket_purchases")
  .select("user_id")
  .eq("event_id", eventId)
  .not("user_id", "in", supabase.raw("select user_id from winner_history"))
  .order("random")
  .limit(1);

Or equivalent SQL via rpc or raw query.

Ensure the logic is robust against:
- No remaining eligible users
- Network errors
- Supabase errors

- Look up profiles.role
- If role !== 'admin', return 403
