### 2. Sweep UI components to use cinematic classes

Apply the following replacements across the project:

- Replace all <button> elements with:
  <button className="cinematic-button">...</button>

- Replace login/signup buttons with:
  <button className="cinematic-button-accent">...</button>

- Replace logout buttons with:
  <button className="cinematic-button-danger">...</button>

- Replace all <input> elements with:
  <input className="cinematic-input" ... />

- Replace all <textarea> elements with:
  <textarea className="cinematic-input cinematic-textarea" ... />

Do not modify logic — only update className attributes.
