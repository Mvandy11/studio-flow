Diagnosis

- Relevant log lines show Netlify packaging functions then failing to install a dependency required by the function:
  - Packaging functions: [line 84](#L84) and the function name at [line 85](#L85).
  - The dependency error: [lines 91–96](#L91-L96) indicate "Cannot find module 'qs'" required by netlify/functions/stripe-webhook.js.
- Error type: Missing runtime dependency for a Netlify Function. The bundler cannot find the npm package "qs" because it is not listed in the site's top-level package.json (or was not committed).
- Cause: stripe-webhook.js requires 'qs' but that package is not declared in the repository's top-level dependencies, so Netlify's function bundling fails.

Solution

1. Verify the function file was committed
   - Confirm netlify/functions/stripe-webhook.js exists in the repo (example: https://github.com/Mvandy11/studio-flow/blob/main/netlify/functions/stripe-webhook.js). If it is missing, commit it.

2. Verify and add the missing package to top-level package.json
   - Check that "qs" is present in the repository root package.json. If it is not, add it as a production dependency. From the project root run (pnpm is used in your build):
```bash
pnpm add qs --save-prod
```
   - If you use npm:
```bash
npm install qs --save
```

3. Commit and push the changes
   - Commit package.json and the lockfile (pnpm-lock.yaml or package-lock.json):
```bash
git add package.json pnpm-lock.yaml
git commit -m "chore: add qs dependency required by stripe webhook function"
git push
```

4. Re-deploy on Netlify
   - Trigger a new build on Netlify. The function bundler should now find "qs" in the top-level dependencies and proceed.

Notes and troubleshooting
- If other "Cannot find module" errors appear for other packages required by functions, repeat the same steps (verify the function file is committed, then add the missing package to the top-level package.json and push).
- If you need to change Node versions on Netlify for any Node-related errors, see Netlify docs: https://docs.netlify.com/configure-builds/manage-dependencies/#node-js-and-javascript

Why this fixes it
- Netlify requires function dependencies to be declared in the site's top-level package.json so the bundler can install and include them when packaging functions. Adding "qs" ensures the bundler can install and bundle it for stripe-webhook.js.
