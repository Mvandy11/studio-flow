You are implementing the Creator Revenue Pool system for Studio Flow.
This system collects $25 from each creator_50 membership and all event
donations, then distributes the total monthly to creators.

Make the following changes:

────────────────────────────────────────
1. CREATE A NEW TABLE: revenue_pool
────────────────────────────────────────

revenue_pool:
  id uuid primary key default uuid_generate_v4()
  month text  -- e.g. "2026-05"
  total_amount numeric default 0
  created_at timestamp default now()

────────────────────────────────────────
2. CREATE A NEW TABLE: revenue_pool_entries
────────────────────────────────────────

revenue_pool_entries:
  id uuid primary key default uuid_generate_v4()
  creator_id uuid references profiles(id)
  amount numeric
  source text  -- "subscription" or "donation"
  created_at timestamp default now()

────────────────────────────────────────
3. ADD LOGIC FOR CREATOR_50 ACTIVATION
────────────────────────────────────────

When membership_tier = "creator_50" is activated:

Insert into revenue_pool_entries:
{
  creator_id: user.id,
  amount: 25,
  source: "subscription"
}

────────────────────────────────────────
4. ADD LOGIC FOR DONATIONS
────────────────────────────────────────

When a donation is recorded:

Insert into revenue_pool_entries:
{
  creator_id: event.creator_id,
  amount: donation.amount,
  source: "donation"
}

────────────────────────────────────────
5. MONTHLY POOL CALCULATION
────────────────────────────────────────

Add a backend route or cron job:

- Sum all revenue_pool_entries for the current month
- Insert into revenue_pool:
  { month: "YYYY-MM", total_amount }

────────────────────────────────────────
6. CREATOR PAYOUT CALCULATION
────────────────────────────────────────

For each creator:
- Sum all revenue_pool_entries where creator_id = creator.id
- Display this in the creator dashboard under:
  "Monthly Earnings"

────────────────────────────────────────
7. CREATOR DASHBOARD UI
────────────────────────────────────────

Add:
- "My Monthly Earnings"
- "My Revenue Pool Contributions"
- "My Donations Received"

8. TESTING CHECKLIST
